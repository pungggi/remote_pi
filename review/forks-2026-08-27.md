default branch against `upstream/main` (GitHub compare API), then per-commit
inspection of the forks carrying real work. 82 forks total, ~15 with commits
ahead, ~4 directly relevant to Piper.

1. **PR #64 (our ask_user mobile work) was merged upstream on 2026-08-06**
   ("feat: renderiza ask_user (pi-ask) no mobile via extension_ui_request").

   brings the squashed version of our own 17 commits → on ask_user files,
   keep `--ours` **after** confirming upstream didn't change the logic
   (upstream later shipped plan/42-ask-user-cancel and plan/57-app-ask-user-ui,
   so it may have evolved).

   Upstream landed plan/57 (their own ask_user), plan/61 (Windows as remote

## Ranked takeaways for Piper

1. **Triage the ydtb audit against our tree** → [`plan/133`](../plan/133-external-audit-triage.md).
   Quick status from initial verification: their C1 (relay forging app→Pi
   frames) is already closed here — stronger than their fix — by plan/130's
   inner signatures (v2 dest-binding, replay dedup, dual-sign transition);
   C2 (unsigned `pair_request`) appears closed by proof-of-possession via the
   v2 sig bound to the claimed epk (verify the auto-listener path). Still
   open: H3 (`rpc_child` stdin has no error handler → EPIPE can kill the
   supervisor), the H4 exit-0-on-already-running silent-DoS angle
   (`bin/supervisord.ts:89-91`) and the unverified "libuv DACL restricts to
   the user" claim (`daemon/supervisor.ts:249`), M3 (`_removeStaleSock`
   check-then-unlink race, `leader_election.ts:111-114`), M4
   (`Broker.close()` hangs with unregistered connections).
2. **Sync upstream now, in smaller steps from now on.** The 317-commit cliff
   plus the PR #64 squash makes every additional week costlier. Consider a
   check-only drift workflow (leoliu0 pattern, report instead of push).
3. **TLS-LAN has a working blueprint** (lionweb1989) sized exactly for
   plan/130's deferred wss slot.
4. **We don't commit `dist/`** (`.gitignore:14`) — four separate forks added
   exactly that so `pi install github:…` works. tipybara instead ships a
   root wrapper loading `src/index.ts` straight from git (no dist churn),
   at the cost of a patch ledger. Conscious decision to make; not urgent.
5. **Watch list (upstream PRs):** #132 (OMP ask bridge — our ask_user
   territory), #148/#149 (REMOTE_PI_DIR + global config defaults), #122
   (rename event API — plan/41-adjacent), #128 (relay reconnect retry —
   already ported here as #57), #124 (ours).
